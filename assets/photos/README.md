# Фотографии автомойки 4 Поста

Укажите номер с главной страницы при отправке снимка. Например, «Фото №15» — въезд с улицы.

| № | Что снять | Ключ для сайта |
| --- | --- | --- |
| 1 | Главное фото | `hero` |
| 2 | Мойка автомобиля | `wash` |
| 3 | Химчистка салона | `interior` |
| 4 | Полировка кузова | `polish` |
| 5 | Защитные покрытия | `protection` |
| 6 | Шиномонтаж | `tires` |
| 7 | Мототехника | `moto` |
| 8 | Автомойка | `about` |
| 9 | Общий вид | `gallery-1` |
| 10 | Зона мойки | `gallery-2` |
| 11 | Уход за кузовом | `gallery-3` |
| 12 | Уход за салоном | `gallery-4` |
| 13 | Шиномонтаж | `gallery-5` |
| 14 | Зона ожидания | `gallery-6` |
| 15 | Въезд с улицы | `entrance` |

Чтобы разместить снимок, положите его в `assets/photos/` в формате WebP или AVIF и добавьте запись в объект `photos` в `js/home.js`. Укажите путь от корня сайта в `src` и описание снимка в `alt`. При необходимости задайте `srcset`, `sizes` или отдельный файл для увеличения в `full`.
