# Фотографии «4 ПОСТА»

Сохраните согласованные с владельцем кадры в этой папке в WebP или AVIF.
Подключите их в объекте `photos` в `js/home.js`.

| Ключ | Что разместить |
| --- | --- |
| `hero` | Главная фотография комплекса или автомобиля |
| `wash`, `interior`, `polish`, `protection`, `tires`, `moto` | Фотографии соответствующих услуг |
| `about` | Фотография комплекса |
| `gallery-1`–`gallery-6` | Комплекс, зона мойки, кузов, салон, шиномонтаж, зона ожидания |
| `entrance` | Фотография въезда с улицы |

Поля записи: `src`, `alt`, при необходимости `srcset`, `sizes` и `full`
для увеличенного кадра. Пути указывайте от корня проекта.
