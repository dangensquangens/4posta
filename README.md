# 4 ПОСТА

Сайт автомойки 4 Поста на Малой Пироговской, 8, в Москве. На главной — услуги, фотографии и контакты. В прайсе — цены для пяти категорий автомобилей и двух категорий мототехники, тарифы на шиномонтаж и ремонт шин.

## Структура

| Путь | Содержимое |
| --- | --- |
| `index.html` | Главная страница |
| `prices.html` | Полный прайс и навигация по его разделам |
| `data/prices.js` | Цены, категории, сноски и ссылки на страницы PDF |
| `css/` | Общие стили и локальное подключение Manrope и Inter |
| `js/` | Мобильное меню, главная страница, галерея и прайс |
| `assets/brand/` | Знак из PDF, его три пиктограммы и favicon |
| `assets/photos/` | Номера мест для фото и инструкция по загрузке |
| `assets/fonts/` | Локальные шрифты и их лицензии |
| `scripts/` | Сервер предпросмотра и проверка цен |
| `robots.txt`, `sitemap.xml`, `.nojekyll` | Файлы для статической публикации |

## Локальный запуск

Из корня репозитория запустите сервер и откройте [главную страницу](http://127.0.0.1:4173/).

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Можно запустить и через `npm run dev`. Сайт публикуется без сборки.

## Обновление прайса

Редактируйте `data/prices.js`. Порядок пяти автомобильных цен соответствует массиву `carCategories`, а двух мотоциклетных — массиву `motoCategories`. В ремонте шин у каждой позиции одна цена. Цены хранятся в целых рублях. `priceType: 'from'` добавляет пометку «от», а `fixed` выводит фиксированную цену. Поле `notes` содержит ключи сносок, поле `sourcePage` — номер страницы PDF. Сохраняйте идентификаторы услуг, чтобы продолжали работать ссылки с главной страницы.

Для шиномонтажа найдите тариф по типу автомобиля, типу шины и диаметру. Укажите четыре операции и итог за одно и четыре колеса согласно PDF. После обновления выполните проверку. Если официальный прайс изменился, обновите контрольные значения и количество позиций в проверочном скрипте в соответствии с новым документом.

```sh
npm test
npm test -- "/путь/к/4 ПОСТА прайс-лист 2026-2027.pdf"
```

Для второй команды нужен `pdftotext` из Poppler. Она сравнивает цены и пометки «от» с PDF построчно. Состав процедур и сноски сверяйте с документом при каждом обновлении. Номера для каждого кадра приведены в [инструкции по фото](assets/photos/README.md). Подтверждённое описание въезда можно добавить в контактный раздел `index.html`.

## Публикация на GitHub Pages

1. Используйте репозиторий `dangensquangens/4posta`. Для GitHub Free нужен публичный репозиторий.
2. Если проект получен в ZIP-архиве, распакуйте его и выполните из папки проекта.

   ```sh
   git init -b main
   git add .
   git commit -m "Initial 4 Posta website"
   ```

3. Если в локальном репозитории ещё нет `origin`, добавьте его первой командой. Затем отправьте ветку `main`.

   ```sh
   git remote add origin https://github.com/dangensquangens/4posta.git
   git push -u origin main
   ```

4. В репозитории откройте **Settings → Pages → Deploy from a branch**. Выберите **main → / (root)** и сохраните настройку.
5. После завершения публикации откройте [адрес сайта](https://dangensquangens.github.io/4posta/) и проверьте переход на `prices.html`.

Если адрес публикации изменится, обновите canonical и Open Graph в обеих HTML-страницах, абсолютные URL в Schema.org, `sitemap.xml` и ссылку на него в `robots.txt`. На GitHub Pages файл `robots.txt` из проекта будет доступен по пути `/4posta/robots.txt`. Для поисковых роботов правила индексации определяет `robots.txt` в корне домена. Sitemap проекта можно отправить в панель вебмастера отдельно.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
